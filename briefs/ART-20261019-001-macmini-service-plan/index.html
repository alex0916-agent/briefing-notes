01

검토 결론

기존 웹서비스를 한 화면에서 확인하고, 실제 결과를 검증하며 제어하는 개인용 독립 관리 앱을 제안합니다. 이번 산출물은 구현 전 종합계획과 디자인 검토안입니다.

판단근거의미
구현 가능기획 원본과 실제 서비스 연결·실행 설정을 읽기 전용 확인독립된 작은 앱으로 시작 가능
우선 대상 3종Hermes Dashboard · HaccpOS Platform · Planfold복수 주소의 같은 서비스는 하나로 관리
작동 확인은 별도현재 조사는 설정·기획 확인이며 제어 시험을 수행하지 않음가동·복구 성공으로 확대 해석하지 않음
디자인 방향 제안FlyonUI 패턴 + 제한적 Dribbble 위계 참고명료한 목록·상세와 모바일 카드
검토 후 구현현재 코드·운영 설정·서비스 조작 미착수범위·화면 방향 승인 이후 착수
이번에 확인할 결정

개인용 3종 관리 범위, 목록+상세/모바일 카드 구조, 아래 컬러와 스타일, 로그인 후 가용성 기준을 검토해 주세요.

02

목표·현재까지의 조사

기획 프로젝트의 초기 표현은 Tascale 서비스 관리였으며, 실제 요구는 현재 Mac mini에서 Tailscale로 제공하는 웹서비스의 가동 현황 확인·시작·정지·재시작입니다. 맥북과 모바일 브라우저에서도 사용합니다.

구분확인한 내용확인 수준
기획PRD v1/rev6 · 기능명세 · 12장 시안 · handoff로컬 원본 읽기
대상웹서비스 3종·같은 프로세스의 중복 접속 경로운영 설정 읽기
제어 기반사용자 서비스 관리자·자동 시작 설정 존재정의 확인, 실제 제어 미실행
디자인8개 참고 사이트·Canva 지정 템플릿범위는 출처표에 개별 명시
잔여 조사의존성·진행 작업 조회·접근 정책구현 전 확정 필요

기획 시안은 정보 구조의 입력입니다. 기존 워크스페이스 시안을 실제 운영 UI 또는 검증 완료된 기능으로 간주하지 않습니다.

03

기능 범위·제외 범위

포함사용자에게 보이는 결과
상태 조회·새로고침가동/중단/확인 불가, 마지막 확인 시각, 판정 이유
서비스 열기등록된 접속 주소만 열기·같은 대상 중복 제어 없음
시작·정지·재시작대상 확인 → 처리 단계 → 실제 상태 기반 결과
작업 결과접수·명령 처리·후속 확인과 오류 이유 구분
개인 인증·자동 시작만료 세션, 로그인 후 관리 앱 가용성

v1 제외: 기존 서비스 코드 배포·업데이트, 다중 사용자, 결제, 장기 통계·로그 분석, 관리 대상 자동 장애 복구, 로그인 전 가용성 보장. 관리 앱 자신을 목록에서 정지하는 기능도 제공하지 않습니다.

04

구조·데이터·제어 경계

01맥북·모바일 브라우저
02비공개 네트워크·인증
03관리 서버·허용 목록·작업 잠금
04운영체제 서비스 관리자
05기존 웹서비스

작은 Node.js 서버와 정적 HTML·CSS·JavaScript, 앱 전용 JSON 설정·최소 작업 결과를 제안합니다. 기존 서비스의 소스·데이터와 분리합니다. 시각 참고를 이유로 React·DB·컴포넌트 라이브러리를 추가하지 않습니다.

영역책임
서비스 설정ID·이름·허용 대상·상태 기준·필수 의존성·열기 링크
상태 어댑터등록 프로세스·HTTP·의존성 판정, 확인 시각/사유
제어 어댑터고정 실행 파일/인수·서비스별 허용 작업·제한된 대기
작업 결과요청ID·대상·행동·시각·단계·결과, 기밀값 제외
브라우저명확한 상태/제어 영향/결과, 임의 명령 입력 금지

운영 주소·포트·로컬 경로·실행 label은 비공개 원본에서 관리하며 이 공개 보고서에 싣지 않습니다.

05

안전한 제어·상태 판정

표시판정 원칙가능한 다음 행동
가동 중등록 프로세스·서비스별 HTTP·필수 의존성 확인열기 / 정지 / 재시작
중단프로세스와 해당 로컬 연결 부재 확인시작
확인 불가조회 오류·시간 초과·응답/프로세스 불일치사유 확인 / 다시 확인
처리 중접수 후 실행·목표 상태 확인 중단계 표시·해당 대상 제어 잠금
  • 명령 종료 코드만으로 성공 처리하지 않고 목표 상태를 확인합니다. 재시작은 이전 프로세스 전환도 검증합니다.
  • 같은 서비스에는 한 작업만 허용합니다. 요청 식별자로 중복 클릭·재접속 중복 실행을 막습니다.
  • 단절로 접수 여부를 모를 때는 명령을 자동 재전송하지 않고 상태·작업 결과를 조회합니다.
  • 정지·재시작 전 대상과 영향을 표시합니다. 진행 작업이 있거나 조회에 실패하면 제어를 차단합니다.
  • KeepAlive 서비스의 정지도 서비스 관리자와 일관되게 구현합니다. 임의 PID 종료·임의 shell·기본 sudo는 사용하지 않습니다.
  • 기본은 접속/수동 새로고침 때 조회합니다. 제어 중에만 제한된 후속 확인을 하며 실제 확인 간격·대기 시간은 실측 후 정합니다.
06

접근·자동 시작·복구

  • 비공개 HTTPS 경로·서버 로컬 바인딩·실제 접근 정책 확인을 기본으로 합니다.
  • 앱 로그인·만료 세션·요청 출처와 CSRF 검증·서비스/행동 허용 목록을 둡니다. 비밀번호 평문·전체 프로세스 환경을 기록하지 않습니다.
  • 관리 앱은 사용자 로그인 후 자동 시작을 제안합니다. 실제 로그인 전 부팅/잠금 해제 가용성을 보장하지 않습니다.
  • Mac mini 전원 꺼짐·Tailscale 단절은 같은 기기의 웹 관리 앱으로 복구할 수 없습니다. 대체 수동 복구 안내가 필요합니다.
  • 실제 원격 제어 활성화·접근 변경·자동 시작 설치·운영 서비스 정지/재시작·재부팅은 구체적 적용 범위와 검증 시간 승인 후 수행합니다.

롤백은 관리 앱 전용 등록과 새 관리 경로만 제거하는 범위입니다. 기존 서비스 정의·주소·데이터를 일괄 초기화하지 않습니다.

이번 보고서의 Canva 템플릿

선택한 공개 템플릿은 Taty Studio — Blue White Simple Minimalist Professional Company Project Proposal A4입니다. ID EAG0US653cc. 공개 상세에서 무료 템플릿 표기·표지·목차 실물을 확인했습니다.

큰 좌측 정렬 제목·넓은 흰 여백·파란 절 번호/구분선·정돈된 목차를 이 웹 보고서에 조정 적용했습니다. 원본 상품 목업·사진·로고·장식 자산은 복제하지 않았습니다. 정확한 Canva 원본 사본 또는 템플릿 파일 복제를 완료했다고 주장하지 않습니다.

보고서의 편집 디자인은 Navy #10213A · Blue #2563EB · White #FFFFFF · Paper #F8FAFC입니다. 제품 UI 자체의 팔레트와 구분합니다. 사용자 명시에 따라 이번 문서의 시각 템플릿은 기본 프리셋보다 우선 적용하며 목차·접기/펼치기·읽기 진행·인쇄 기능을 제공합니다.

Canva 편집용 문서도 생성했으며 본문 추출로 주요 내용을 확인했습니다. Canva Docs의 연속 문서 형식이므로 확정된 13쪽 PDF가 아닙니다. 편집본은 연결된 계정 권한으로 별도 열며, 이 웹 보고서를 통합 검토본으로 사용합니다.
