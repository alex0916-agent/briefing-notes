1. 목적

현재 올젠케어의 전력관제, 온도, 압력, 카운트 센서 등이 MQTT 통신을 지원하고 있으므로 이를 Haps™와 연동하기 위한 공통 MQTT 계약과 Edge 표준을 정의합니다.

AllgenCare MQTT
→ Haps Edge Adapter
→ Haps Canonical Data Model
→ Event / Time-Series
→ ThemisAX / AegisAX / Haps Context
→ Haps™ AI 분석·경보·업무조치

5. Haps Canonical Payload

{
  "schema_version": "1.0",
  "tenant_id": "vina01",
  "plant_id": "plant01",
  "line_id": "line01",
  "asset_id": "compressor01",
  "device_id": "sensor01",
  "metric": "pressure",
  "value": 6.82,
  "unit": "bar",
  "quality": "GOOD",
  "timestamp": "2026-09-15T05:30:21.315Z",
  "sequence": 128394
}
기존 올젠케어 MQTT Payload를 무리하게 변경하지 않고, Haps Edge Adapter에서 Canonical Format으로 변환하는 것을 기본 원칙으로 합니다.

9. QoS / Retain / LWT

  • Telemetry: QoS 1 권장
  • Retain 권장: Device Status, Current Configuration, Latest State
  • Retain 비권장: 고주기 Telemetry, Event History
  • LWT: Gateway/Device ONLINE/OFFLINE 상태 관리
Topic:
alexlab/vina01/plant01/device/gateway01/status

ONLINE:
{ "status": "ONLINE" }

OFFLINE:
{ "status": "OFFLINE" }
